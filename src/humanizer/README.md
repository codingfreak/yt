# ASP.NET Blazor and Humanizer

After I strolled around on the Nuget stats page for some time I found a package called Humanizer.Core in the Top-10. Because I did not know what this was I dug a little bit deeper, found out that it is actually cool and decided to do a video on this. This is why this here exists.

Problem is (as always with me) that this video now also is a little introduction into Blazor (a UI-tech for the web from Microsoft). So here we are! It is a mix of Humanizer, Blazor and random discussions with myself.

Run `dotnet run -lp Web --project .\src\Ui.WebApp\` in the folder of this file and the open the [page](https://localhost:7202) in the broweser.
